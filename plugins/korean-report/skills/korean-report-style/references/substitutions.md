# 치환 목록

`SKILL.md` §1의 전체 사례. 검사와 제한적 자동 교정은 이 표를 단일 원천으로 삼는다.
기존 두 열 표는 `all`·`literal`로 읽고, 필요할 때만 `검사 범위`와 `검출 방식` 열을 둔다.

**이 표는 예시이지 목록이 아니다.** 표에 없다고 통과가 아니며, `SKILL.md` §6의
판정법(§1.3 주어 치환 · §1.8 목적어 치환)을 함께 적용한다.

예시는 가상 사례 「A사 — 인라인 계측 체계 확립과 수율 개선」에서 가져왔다.

### 7.2 외래어 표기

**규격에 등장하는 말은 영문**으로 표기한다. 문서와 코드·API 문서가 1:1로 대조되는 것을 전제로 한다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| 세션 키 | `session key` |
| 페이로드 | `payload` |
| 엔드포인트 | `endpoint` |
| 콜백 | `callback` |

식별자 · enum · 필드명은 번역하지 않는다 — `SUCCESS`, `waferId`, `InspectionStarted`.

**단, §9의 정착 용어는 한글 음차를 유지한다.** `드리프트` · `뉴슨스` · `빈닝`은
규격상의 이름이 아니라 분야에서 굳어진 개념어이며, 영문으로 되돌리면 오히려 읽기 비용이 증가한다.

| 구분 | 표기 | 판정 |
|---|---|---|
| 규격 · API에 등장 | 영문 | 코드·문서에 같은 철자로 존재하는가 |
| 분야 정착 개념어 | 한글 음차 | 우리말·영문 어느 쪽도 더 정확하지 않은가 |

## 9. 바꾸지 않는 것

아래는 비유가 아니라 **용어**다. 순진하게 옮기면 정밀도가 떨어지는 정도가 아니라
**뜻이 달라진다.** 아래 표의 가운데 열이 흔히 저지르는 오역이다.

| 용어 | 흔한 오역 | 무엇이 틀리는가 |
|---|---|---|
| `오버레이` | 정렬 | 오버레이는 층간 정렬 **정확도**다. 장비 동작인 alignment 와 다른 말이다 |
| `뉴슨스` | 무해 결함 | 검출은 되었으나 수율에 영향이 없다는 **판정 결과**라는 뜻이 빠진다 |
| `킬러` | 치명 결함 | 「수율에 영향을 준다」는 판정 기준이 사라진다 |
| `스큐` | 편차 | 스큐는 분포의 **비대칭**이다. 분산과 다른 양이다 |
| `빈닝` | 등급 분류 | 테스트 결과에 따라 나눈다는 조건이 빠진다 |
| `시그니처` | 패턴 | 웨이퍼 맵의 **공간적** 패턴이라는 뜻이 빠진다 |
| `시즈닝` | 길들이기 | 챔버 안정화의 특정 절차명이다 |
| `드리프트` | 이탈 | 시간에 따른 **완만한** 이동이라는 뜻이 빠진다 |
| `CD` | 임계값 | CD는 임계치수(critical dimension)다. threshold 와 무관하다 |
| `Cpk` | 공정 능력 | 규격 중심에서 치우친 정도를 함께 반영한다는 점이 빠진다 |
| `디펙` | 결함 | defect · fault · failure 의 구분이 사라진다 |
| `리워크` | 재작업 | 특정 공정을 되돌려 다시 수행한다는 정의가 빠진다 |

조직·레포에 굳어진 표현도 임의로 바꾸지 않는다. 외부 문서에서는 처음 나올 때 한 번 풀어 쓴다.

예 — `골든 웨이퍼`(기준 시료를 뜻하는 내부 용어), `핫 로트`(우선 처리 로트)
