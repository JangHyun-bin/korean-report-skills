# 형태소 규칙

`lint.py` 가 형태소 분석기(`kiwipiepy`)로 검사하는 규칙. 이 표를 고치면 검사도 함께 바뀐다.

## 치환표와의 역할 구분

| | `substitutions.md` | 이 표 |
|---|---|---|
| 검사 단위 | 문자열 | 형태소 |
| 활용형 | 행마다 필요 | 자동 |
| 조사 개입 | 놓친다 | 무관 |
| 담당 | 관용구 · 어미 축약 | 어간 · 단위 명사 · 문체 |

**어미 축약(`했다` → `하였다`)은 여기 두지 않는다.** 형태소 분석기가 `했다`와 `하였다`를
동일한 `하/VV + 였/EP + 다/EF` 로 정규화하므로 두 형태가 구분되지 않는다.
표면형 검사가 맞으며 치환표 §1 이 담당한다.

**관용구도 여기 두지 않는다.** `반토막이 된다` · `진짜 범인` 은 형태소 조합으로 특정되지
않는다. 치환표가 담당한다.

## 1. 동사 어간 — 광의 고유어

의미역이 넓은 고유어 어간이다. 활용형과 무관하게 어간으로 판정하므로
`다룬다` · `다루었다` · `다루며` 가 한 행에 걸린다.

핵심은 항상 보고하고, 주의는 `--all` 에서만 보고한다.
**정당한 용법이 많은 어간을 항상 보고하면 검사기가 소음이 되고, 소음이 되면 꺼진다.**

`막` 은 주의에서 핵심으로 옮겼다. 기술 문서에서 이 어간의 목적어는 대개 물리적 입구가 아니라
지시 · 요청 · 경로 · 사태이며, 그 경우 보류 · 차단 · 방지 중 어느 것인지 분기한다.

### 1.3 비교 없는 크기 서술

크기 형용사는 같은 절에 비교 조사 `보다` 나 비교 부사(`가장` · `더` · `덜` · `훨씬`)가 있으면
비교 서술이므로 통과한다. 관형형(「작은 값」)도 대상을 지시하는 수식이므로 통과한다.
비교 대상 없이 서술어로 쓰면 정도를 뭉뚱그린 서술이 되므로 보고한다.
그래서 「임계값보다 크면」 은 통과하고 「비용이 크다」 는 걸린다.

| 어간 | 대안 | 통과하는 용법 |
|---|---|---|
| 크 | 높다 · 상당하다 · 수치로 기재한다 | 「임계값보다 크다」 |
| 작 | 낮다 · 미미하다 · 수치로 기재한다 | 「반경보다 작다」 |
| 커지 | 증가한다 · 확대된다 | 「기준보다 커진다」 |
| 작아지 | 감소한다 · 축소된다 | 「기준보다 작아진다」 |

## 2. 동사 어간 — 유정물

**주어가 무정물이면 의인화다.** 주어 탐지는 형태소 분석기가 수행하며,
주격 조사 또는 보조사가 붙은 직전 명사를 주어로 본다.

| 어간 | 대안 |
|---|---|
| 죽 | 불량으로 판정된다 |
| 살 | 잔존한다 |
| 앉 | 부착된다 |
| 늙 | 노후화된다 |
| 갉 | 저하시킨다 |
| 흐르 | 통과한다 |
| 튀 | 이상치가 발생한다 |
| 밀리 | 적체가 발생한다 |
| 자 | 정지한다 |
| 깨 | 재기동한다 |
| 숨 | 노출되지 않는다 |
| 걷 | 이동한다 |
| 뛰 | 급증한다 |
| 묻 | 판정하지 않는다 · 검토한다 |

### 2.1 유정물 명사

아래 명사가 주어면 의인화가 아니다. 검사에서 제외한다.

```
사람 관람객 관객 이용자 사용자 고객 작업자 운영자 담당자 관리자 개발자 엔지니어
직원 인원 감독 팀 팀원 참가자 응시자 방문객 승객 학생 교사 의사 환자 아이 어른
```

## 3. 단위 명사

단위 명사는 세는 대상의 부류를 지시한다. 부류가 어긋나면 문서가 구어처럼 읽힌다.
**세는 대상은 무한하지만 단위는 닫힌 부류다.** 그래서 대상이 아니라 단위를 목록화한다.

### 3.1 허용

기술 문서에서 통상 사용하는 단위다. 이 목록에 있으면 통과한다.

```
개 건 종 항 부 회 차 열 단 면 매 대 기 식 조 명 점 번 쪽 칸 층 동 호 실
초 분 시 일 주 개월 년 배 위 등 원 명 인 절 항목 세트 단계 계열 계통
```

### 3.2 검토

| 단위 | 원래 세는 대상 | 대안 |
|---|---|---|
| 벌 | 옷 · 수저 · 활자 | 종 · 부 |
| 마리 | 짐승 | — |
| 자루 | 긴 물건 | 개 · 정 |
| 채 | 건물 | 동 |
| 척 | 배 | — |
| 포기 | 풀 | — |
| 그루 | 나무 | — |
| 켤레 | 신발 · 양말 | 종 |
| 톨 | 낟알 | 개 |

**`가지` 와 `겹` 은 넣지 않는다.** 「세 가지 방식」은 종류를, 「헤어라인 한 겹」은
포개진 층을 세는 정상 용법이며 부류가 어긋나지 않는다.
의미역이 넓다는 이유만으로 검출하면 소음이 되고, 소음이 되면 검사기가 꺼진다.

**분야에 정착한 용법은 예외로 둔다.** 활자·서체를 「한 벌」로 세는 것은 제작 분야의
표준 표현이다. 검출되면 `<!-- style-exempt -->` 로 표시하고 유지한다.

## 4. 문체 혼용

**한 문서에서 평서체와 합니다체를 섞지 않는다.** 종결 어미로 판정한다.

| 어체 | 종결 어미 |
|---|---|
| 평서체 | 다 · ᆫ다 · 는다 · 이다 |
| 합니다체 | `니다` 로 끝나는 모든 종결 어미 |

합니다체를 자모로 나열하지 않는다. 분석기가 `보입니다` 의 어미를 종성 ㅂ(U+11B8) 로 출력하는데
초성 ㅂ(U+1107) 을 적어 두면 `습니다` 를 뺀 모든 합니다체가 검사를 빠져나간다.

소수 쪽을 보고한다. 문서 본문과 커버레터를 분리해야 하는 신호다.

### 4.1 파일별 기대 어체

아래 파일은 어체가 정해져 있다. 다수·소수를 세지 않고 **기대와 다른 어체를 전부 보고한다.**

선은 독자로 가른다 — **바깥 사람에게 말을 거는 안내문은 합니다체,
규칙·기록과 agent 가 읽는 문서는 평서체다.** 새 파일을 넣을 때도 이 선으로 가른다.

| 파일 | 기대 |
|---|---|
| README.md | 합니다체 |
| CONTRIBUTING.md | 합니다체 |
| SECURITY.md | 합니다체 |
| INSTALL.md | 합니다체 |
| CHANGELOG.md | 평서체 |

## 5. 형용사 활용

**형용사 어간에 동사 평서형 어미(`ᆫ다` · `는다`)를 붙이지 않는다.**
`필요하다` `중요하다` `가능하다` 는 형용사이므로 `필요한다` 는 틀린 활용이다.

<!-- style-teaching -->

| 틀림 | 맞음 |
|---|---|
| 필요한다 | 필요하다 |
| 필요하지 않는다 | 필요하지 않다 |

판정은 어간의 품사 tag 로 한다 — `하/XSA` 는 형용사, `하/XSV` 는 동사다.
`~하다` 파생 형용사만 본다. 고유어 형용사는 동형어가 많아서 제외한다 —
`압박으로 적지 않는다` 의 `적-` 은 기록하다의 동사인데 분석기가 `적다`로 읽는다.
그래서 `검사하지 않는다` 는 통과하고 `필요하지 않는다` 는 걸린다.
보조 용언 `않` `못` 은 품사를 스스로 정하지 않고 본용언을 따르므로 건너뛰고 앞을 본다.

표가 필요한 규칙이 아니다. 어간 목록이 아니라 tag 조합으로 판정하므로
새 형용사를 표에 추가할 일이 없다.
