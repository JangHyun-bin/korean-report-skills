# 형태소 규칙

`lint.py` 가 형태소 분석기(`kiwipiepy`)로 검사하는 규칙. 이 표를 고치면 검사도 함께 바뀐다.

## 치환표와의 역할 구분

| | `substitutions.md` | 이 표 |
|---|---|---|
| 검사 단위 | 문자열 | 형태소 |
| 활용형 | 행마다 필요 | 자동 |
| 조사 개입 | 놓친다 | 무관 |
| 담당 | 관용구 · 어미 축약 | 어간 · 단위 명사 · 문체 |

**어미 축약(`했다` → `하였다`)은 여기 두지 않는다.** 형태소 분석기가 `했다`와 `하였다`를
동일한 `하/VV + 였/EP + 다/EF` 로 정규화하므로 두 형태가 구분되지 않는다.
표면형 검사가 맞으며 치환표 §1 이 담당한다.

**관용구도 여기 두지 않는다.** `반토막이 된다` · `진짜 범인` 은 형태소 조합으로 특정되지
않는다. 치환표가 담당한다.

## 1. 동사 어간 — 광의 고유어

의미역이 넓은 고유어 어간이다. 활용형과 무관하게 어간으로 판정하므로
`다룬다` · `다루었다` · `다루며` 가 한 행에 걸린다.

핵심은 항상 보고하고, 주의는 `--all` 에서만 보고한다.
**정당한 용법이 많은 어간을 항상 보고하면 검사기가 소음이 되고, 소음이 되면 꺼진다.**

### 1.1 핵심

| 어간 | 대안 | 갈라지는 의미 |
|---|---|---|
| 다루 | 한정한다 · 규정한다 · 정의한다 | 범위 획정인지 정의인지 |
| 넘기 | 전달한다 · 이관한다 · 위임한다 | 데이터인지 업무인지 권한인지 |
| 갈리 | 분기한다 · 분리된다 | 해석인지 대상인지 |
| 생기 | 발생한다 · 형성된다 | 사태인지 구조인지 |
| 나누 | 구분한다 · 분류한다 · 배분한다 | 경계인지 유형인지 몫인지 |
| 맞추 | 정합한다 · 정렬한다 · 보정한다 | 논리인지 위치인지 값인지 |
| 늦추 | 순연한다 · 유예한다 | 일정인지 의무인지 |
| 지우 | 삭제한다 · 제거한다 · 소거한다 | 항목인지 요소인지 값인지 |
| 긋 | 획정한다 · 구획한다 | 범위인지 구역인지 |

### 1.2 주의

| 어간 | 대안 | 정당한 용법 |
|---|---|---|
| 두 | 배치한다 · 유지한다 · 설정한다 | 「기준을 두다」 |
| 잡 | 검출한다 · 산정한다 · 고정한다 | 「손으로 잡다」 |
| 넣 | 포함한다 · 등재한다 · 삽입한다 | 「용기에 넣다」 |
| 빼 | 제외한다 · 차감한다 | 「부품을 빼다」 |
| 붙이 | 부착한다 · 부기한다 · 첨부한다 | 「라벨을 붙이다」 |
| 만들 | 생성한다 · 작성한다 · 구축한다 | 「부품을 만들다」 |
| 고치 | 수정한다 · 보완한다 · 개정한다 | 「장비를 고치다」 |
| 막 | 차단한다 · 방지한다 | 「입구를 막다」 |
| 늘 | 향상된다 · 증가한다 · 연장된다 | 「길이가 늘다」 |

## 2. 동사 어간 — 유정물

**주어가 무정물이면 의인화다.** 주어 탐지는 형태소 분석기가 수행하며,
주격 조사 또는 보조사가 붙은 직전 명사를 주어로 본다.

| 어간 | 대안 |
|---|---|
| 죽 | 불량으로 판정된다 |
| 살 | 잔존한다 |
| 앉 | 부착된다 |
| 늙 | 노후화된다 |
| 갉 | 저하시킨다 |
| 흐르 | 통과한다 |
| 튀 | 이상치가 발생한다 |
| 밀리 | 적체가 발생한다 |
| 자 | 정지한다 |
| 깨 | 재기동한다 |
| 숨 | 노출되지 않는다 |
| 걷 | 이동한다 |
| 뛰 | 급증한다 |

### 2.1 유정물 명사

아래 명사가 주어면 의인화가 아니다. 검사에서 제외한다.

```
사람 관람객 관객 이용자 사용자 고객 작업자 운영자 담당자 관리자 개발자 엔지니어
직원 인원 감독 팀 팀원 참가자 응시자 방문객 승객 학생 교사 의사 환자 아이 어른
```

## 3. 단위 명사

단위 명사는 세는 대상의 부류를 지시한다. 부류가 어긋나면 문서가 구어처럼 읽힌다.
**세는 대상은 무한하지만 단위는 닫힌 부류다.** 그래서 대상이 아니라 단위를 목록화한다.

### 3.1 허용

기술 문서에서 통상 사용하는 단위다. 이 목록에 있으면 통과한다.

```
개 건 종 항 부 회 차 열 단 면 매 대 기 식 조 명 점 번 쪽 칸 층 동 호 실
초 분 시 일 주 개월 년 배 위 등 원 명 인 절 항목 세트 단계 계열 계통
```

### 3.2 검토

| 단위 | 원래 세는 대상 | 대안 |
|---|---|---|
| 벌 | 옷 · 수저 · 활자 | 종 · 부 |
| 마리 | 짐승 | — |
| 자루 | 긴 물건 | 개 · 정 |
| 채 | 건물 | 동 |
| 척 | 배 | — |
| 포기 | 풀 | — |
| 그루 | 나무 | — |
| 켤레 | 신발 · 양말 | 종 |
| 톨 | 낟알 | 개 |

**`가지` 와 `겹` 은 넣지 않는다.** 「세 가지 방식」은 종류를, 「헤어라인 한 겹」은
포개진 층을 세는 정상 용법이며 부류가 어긋나지 않는다.
의미역이 넓다는 이유만으로 검출하면 소음이 되고, 소음이 되면 검사기가 꺼진다.

**분야에 정착한 용법은 예외로 둔다.** 활자·서체를 「한 벌」로 세는 것은 제작 분야의
표준 표현이다. 검출되면 `<!-- style-exempt -->` 로 표시하고 유지한다.

## 4. 문체 혼용

**한 문서에서 평서체와 합니다체를 섞지 않는다.** 종결 어미로 판정한다.

| 어체 | 종결 어미 |
|---|---|
| 평서체 | 다 · ᆫ다 · 는다 · 이다 |
| 합니다체 | 습니다 · ᄇ니다 |

소수 쪽을 보고한다. 문서 본문과 커버레터를 분리해야 하는 신호다.
