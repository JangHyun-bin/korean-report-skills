# 도해 규약

`assets/figures.py` 의 7종, 외부 SVG 삽입(§7), 그 사용 원칙.

---

## 1. 원칙

**인라인 SVG 만 쓴다.** 확대해도 선명하고, 문서의 색·폰트 토큰을 상속하고,
텍스트가 검색·복사되며, 바이트가 늘지 않는다.

**색은 클래스로 방출한다.** SVG 표현 속성은 CSS 변수를 읽지 못하므로,
`figures.py` 는 hex 대신 클래스를 붙이고 `assets/css/base.css` 가 그것을 토큰에 잇는다.

| token | 채움 class | 선 class |
|---|---|---|
| `--ink` | `fi-ink` | `st-ink` |
| `--ink-3` | `fi-ink48` | `st-ink48` |
| `--accent` | `fi-pri` | `st-pri` |
| `--fig-mid` | `fi-mid` | `st-mid` |
| `--fig-line` | `fi-line` | `st-line` |
| `--fig-soft` | `fi-soft` | — |
| `--fig-pale` | `fi-pale` | — |

class 이름은 1.x 호환을 위해 유지한다. 값은 `assets/css/tokens.css`에 있다.

이 밖에 `fi-canvas`(면 색) · `fi-oncard`(잉크 위 글자) · `fi-none`(채움 없음)이 있다.

**hex 를 박지 않는다.** `fill="#1d1d1f"` 는 흰 바탕에서는 멀쩡하고 `#272729` 다크 타일
위에서는 글자가 사라진다. class 를 쓰면 `tokens.css` 가 다크 surface 의 token 을 교체할 때
도해가 따라온다.

**형태로 구분하고 색으로 구분하지 않는다.** 채움 대 외곽선, 실선 대 파선,
굵기, 크기. 색 범례에 의존하면 흑백 인쇄에서 무너진다.

**액센트는 도해가 존재하는 이유 하나에만 쓴다.** 전부 파랗게 칠하면 아무것도 강조되지 않는다.

**SVG 안에 `font-family="Pretendard"` 를 명시한다.** SVG 는 상속받지 않는다.

**라벨 크기** — 주석 최소 11px, 축·노드 텍스트 12~13px.

**섹션 제목을 도해 안에 반복하지 않는다.** 캡션과 제목이 이미 말한다.

**개념도는 명시한다** — `(개념도)` 를 캡션에 포함한다. 실측으로 오인되면 안 된다.

## 2. 좌표 계산의 위치 — 생성기

브라우저 JS 로 레이아웃을 계산하면 PDF 출력 시 동일하게 실행되지 않는다.
막대 위치 · 곡선 경로 · 축 눈금을 생성기에서 계산해 SVG 에 리터럴로 박는다.

```python
import datetime
b = datetime.date(2026, 6, 1); e = datetime.date(2026, 12, 20)
T = (e - b).days
pct = lambda d: (datetime.date.fromisoformat(d) - b).days / T * 100
```

**SVG 는 y 가 아래로 증가한다.** matplotlib 식 y-up 으로 배치를 계산한 뒤 뒤집지 않으면
행이 역순으로 쌓이고 헤더가 카드 아래에 붙는다. 실제로 겪은 버그다.

**입력이 이상하면 즉시 실패한다.** 기간 0(`start == end`), 뒤집힌 축(`hi <= lo`),
`maxv <= 0`, 알 수 없는 `kind` 는 `ValueError` 를 발생시킨다. 조용히 깨진 도해가 더 나쁘다.

## 3. 7종

### fig_timeline — 마일스톤 배치

D-day 나열, 구간 밴드. 라벨이 겹치지 않게 위아래 교대 배치한다.

```python
fig_timeline(
  marks=[("2026-08-10", "08-10", "규격 초안", True),
         ("2026-08-31", "08-31", "중간보고", True)],
  start="2026-08-09", end="2026-11-06",
  bands=[("2026-09-01", "2026-09-30", "9월 준비", True)],
  note="남은 82일")
```

### fig_gantt — 일정 막대

`kind` 로 성격을 구분한다. `done` 옅은 채움 · `plan` 파란 파선 외곽선 ·
`wbs` 중간 회색 · `key` 진한 잉크. 마커 `kind` 는 `meet`(실선·현재) ·
`gate`(파선·마감) · `pilot`(점선·목표).

HTML 을 반환하며 필요한 CSS(`.gantt` · `.gbar` · `.gmark` · `.gaxis`)는
`assets/css/base.css` 에 있다. 막대 색은 CSS 가 정하고 인라인 `style` 은 위치만 나른다 —
색을 인라인으로 박으면 다크 타일에서 바꿀 수 없다.

### fig_cards — 항목 그리드

검증 케이스, 리스크 유형처럼 병렬 항목. 3열 기본. `title` · `sub` 로 머리글을 단다.
헤더는 전부 같은 색이고 번호로만 구분한다 — 항목마다 색을 다르게 하면 색이 의미를
갖는 것처럼 읽힌다. 행은 위에서 아래로, 설명은 카드 본문의 수직 중앙에 놓인다.

```python
fig_cards(items=[(1, "검색–매처 제약", "후보 연결 규칙 정정\n지연 900 → 590 ms")],
          title="구조적 개선", sub="각 항목은 측정 가능한 결과를 동반한다", cols=3)
```

### fig_flow — 단계 흐름

파이프라인, 처리 순서. 단계 사이에 흐르는 데이터를 화살표 아래 라벨로 단다.
`highlight` 로 한 단계만 강조한다. 화살촉 `marker` id 는 호출마다 달라지므로
한 문서에 여러 개를 넣어도 겹치지 않는다.

### fig_numberline — 분포와 기준선

값들이 흩어진 정도를 보이고 기준값을 파선으로 표시할 때. 라벨은 위아래 교대.

### fig_compare — 두 기준 대비

같은 항목을 두 기준으로 잰 값. 차이 구간을 파선 사각형으로 감싸 **차이 자체가
발견**임을 드러낸다. 주값과 부값의 대소는 가리지 않는다 — 두 값의 순서와 무관하게 구간이 그려진다.

**모든 행이 축 하나(`maxv`)를 공유한다.** 단위나 자릿수가 다른 항목을 함께 놓으면
작은 값의 막대가 보이지 않는다. `900초`와 `5/7`을 같은 그림에 올리지 않는다.
단위가 다르면 그림을 분할하거나 메트릭 카드를 쓴다.

### fig_scatter — 예측 대 관측

모형이 관측을 얼마나 설명하는지. `y = x` 항등선을 회색 파선으로 깔고,
각 점에 예측 대비 배수를 라벨로 단다. 점이 둘이어도 그 배수가 발견이면 충분하다.

## 4. 캡션

```html
<svg class="fig">…</svg>
<p class="figcap">그림 3 · 절대보정 간격이 꼬리 오차에 미치는 영향 (개념도)</p>
```

번호를 붙이고, 가운데 정렬하고, 중간점으로 번호와 설명을 구분한다.
표는 **표 아래**에 `표 n ·` 캡션을 단다.

`figcap(n, text)` · `tblcap(n, text)` 헬퍼가 있다. 캡션 본문은 HTML 로 취급하므로
필요하면 `<b>` 를 쓸 수 있고, 외부에서 온 값은 `esc()` 로 감싼다.

---

## 5. 표

**세로 괘선과 얼룩무늬를 쓰지 않는다.** 헤더 아래 굵은 선 하나, 행 사이 헤어라인.

**첫 열과 마지막 열은 본문 폭에 정렬한다.** 표는 상자가 아니다.

**숫자 열은 우측 정렬**한다. `table.num` 클래스를 쓴다. 자릿수가 맞아야 비교된다.

**하이라이트 행은 표당 하나**만. 기준 사례나 정정 대상을 가리킨다.

**7열 이상은 `wide()` 로 감싼다.** 화면에서는 가로 스크롤, 인쇄에서는 자동 축소된다.

`tbl()` 의 셀은 **원시 HTML** 이다. 배지(`BADGE_MEAS`)와 수식 마커(`⟦I⟧`)를 셀에
직접 넣는 것이 정상 용법이기 때문이다. 외부에서 들어온 값은 `esc()` 로 감싼다.

## 6. 자주 겪는 문제

| 증상 | 원인 | 대응 |
|---|---|---|
| 다크 타일에서 도해 글자가 안 보임 | hex 를 직접 박음 | `fi-*` · `st-*` 클래스로 교체 |
| 카드 두 번째 줄이 첫 줄 위에 그려짐 | y-up 좌표를 뒤집지 않음 | y 를 아래로 증가시킴 |
| 대비 막대의 차이 구간이 사라짐 | 폭이 음수 | 작은 쪽부터 그림 (`sorted`) |
| 간트 막대가 스타일 없이 출력됨 | `base.css` 미삽입 | `mathbuild.js` 로 빌드했는지 확인 |
| 간트 마커가 막대와 어긋남 | 라벨 폭만 더하고 gap 을 뺌 | `--gtrack-x` 를 씀 |
| 도해 제목이 카드에 가림 | viewBox 상단 여백 부족 | y 좌표 하향 · viewBox 확장 |
| 라벨이 곡선과 겹침 | 라벨 y 가 데이터 최대값보다 낮음 | ylim 상향 후 라벨을 그 위로 |
| 표가 페이지 폭 초과 | 열 수 과다 | `wide()` + 인쇄 시 폰트 축소 |
| 표 셀 안 수식이 줄바꿈 | display 수식 사용 | 인라인 수식으로 교체 |
| PDF 에서 도해만 다음 장 | 캡션과 분리됨 | `svg{break-after:avoid}` |
| 한 문서의 화살촉이 전부 같은 색 | `marker` id 충돌 | 최신 `figures.py` 사용 |
| 두 번째 외부 SVG 의 글자가 첫 그림의 글자로 바뀜 | pdftocairo 출력의 id 충돌 | `embed_svg()` 로 삽입 (§7) |
| 외부 SVG 가 본문 폭으로 확대되어 글자가 과대 | 원본 폭이 본문 폭보다 좁음 | 원본 폭을 본문 폭과 일치시킴 · `cls="fig narrow"` |

## 7. 외부 SVG 삽입

네이티브 7종으로 표현할 수 없는 그림 — 수식이 많은 TikZ 도식, matplotlib 그래프 — 은
외부 도구가 생성한 SVG 를 `embed_svg()` 로 삽입한다. 래스터로 변환하지 않는다.

### 경로 — TikZ

```bash
tectonic fig.tex                  # 또는 pdflatex · lualatex. standalone 문서 클래스를 쓴다
pdftocairo -svg fig.pdf fig.svg   # poppler. 글자는 글리프 경로로 변환된다
```

```python
from figures import embed_svg, figcap

svg = embed_svg(open("fig.svg", encoding="utf-8").read(),
                prefix="fig-arch", label="인라인 계측 체계 구성")
BODY += svg + figcap(3, "인라인 계측 체계 구성")
```

matplotlib 은 `savefig` 의 SVG 출력을 그대로 전달한다. `metadata={"Date": None}` 로
생성 시각을 제외하면 다시 생성해도 diff 가 발생하지 않는다.

### 정리 항목

- XML 선언 · DOCTYPE · 앞쪽 주석을 제거한다
- 모든 `id` 와 `href` · `xlink:href` · `url(#…)` 참조에 `prefix-` 접두어를 부여한다 —
  `style` 속성과 `<style>` 안의 참조도 포함한다
- `<style>` 규칙을 그 SVG 안으로 한정한다. matplotlib 의 `*{stroke-linecap:butt}` 가
  본문의 다른 도해에 적용되지 않게 한다
- 루트의 `width` · `height` 를 제거하고 `viewBox` 를 유지한다 — 크기는 `.fig` 가 정한다
- 루트에 `class` · `role="img"` · `aria-label` · `data-embed` 를 부여한다

### 실패 조건

`viewBox` 가 없거나, 루트가 `<svg` 가 아니거나, 없는 id 를 참조하거나, 외부 파일을
참조하거나, id 가 중복되거나, `<style>` 에 at-rule 이 있으면 `ValueError` 로 실패한다.

`prefix` 는 문서 안에서 고유해야 한다. 같은 `prefix` 로 두 번 삽입하면 충돌이 재발한다.

### 크기

`viewBox` 가 본문 폭까지 확대된다. 원본 폭을 본문 폭(paper 720px, 약 540pt)과
일치시켜 작성해야 글자 크기가 본문 글자와 비슷하다. 폭이 좁은 그림은 `cls="fig narrow"` 를 쓴다.

### 색과 배치

원본 색이 그대로 유지되며 token 을 따르지 않는다.

- 밝은 surface 에만 배치한다. 다크 타일 위의 외부 SVG 는 `qa.py` 가 실패로 판정한다
- 원본 색을 유지하는 조건은 `references/design.md` §5.5 를 따른다
- 캡션은 네이티브 도해와 같은 `그림 n ·` 형식이고 번호도 함께 매긴다
- `qa.py` 의 viewBox 넘침 검사는 외부 SVG 에 적용하지 않는다. 브라우저의 `getBBox` 가
  clip 을 무시하므로 clip 으로 잘린 내용을 넘침으로 판정하기 때문이다
